# Football India Backend

NestJS backend scaffold for the Indian Football Community project.

This repository currently contains the requested backend architecture:

- `src/config` for environment-driven application configuration
- `src/common` for shared constants, decorators, guards, filters, interceptors, pipes, utils, and DTOs
- `src/database` for Supabase client placeholders, SQL migrations, seeders, and schema
- `src/modules` for feature-based modules such as auth, fans, clubs, blogs, store, orders, payments, notifications, and admin
- `src/types` for shared domain type placeholders
- `test` for e2e test placeholders
